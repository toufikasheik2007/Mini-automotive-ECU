# Mini-automotive-ECU
Mini Automotive ECU Simulator built using STM32 Nucleo C031C6 on Wokwi, featuring FSM state control, sensor telemetry, and PWM fan control.

---

## ⚡ Features & Capabilities
* **Finite State Machine (FSM):** Real-time engine state management (Off, Normal, Running, Fault).
* **Sensor Telemetry:** Analog temperature/voltage sensor readouts via ADC/UART.
* **PWM Output:** Dynamic fan speed control based on temperature thresholds.
